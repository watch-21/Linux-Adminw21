# Linux Adminw21 v1 — دليل التشغيل

يتطلب البرنامج Linux وBash وPython 3.10 أو أحدث وأدوات النظام اللازمة لكل عملية. تحتاج الواجهة أيضاً إلى مكتبات Qt و`pkexec` ووكيل PolicyKit يعمل ضمن جلسة سطح المكتب. راجع [متطلبات التوزيعات](LINUX_DEPENDENCIES.md).

من مجلد المشروع:

```bash
sudo ./install.sh
adminw21 --gui
```

شغّل الواجهة بحساب المستخدم العادي. تطلب العمليات الإدارية المصادقة عبر PolicyKit. لا تشغّل الواجهة باستخدام `sudo`.

للتثبيت بوضع الطرفية:

```bash
sudo ./install.sh --terminal-only
sudo adminw21 --terminal
```

تعرض لوحة المراقبة بيانات النظام الفعلية والمستخدمين ذوي جلسات الدخول الظاهرة ومجموعاتهم. قد لا تظهر بعض الجلسات الرسومية عند استخدام مصدر utmp. تحتاج معدلات CPU والشبكة والقرص إلى عينتين قبل عرضها. الأداة غير المتاحة أو نقص الصلاحية يظهران كحالة خطأ أو عدم توفر.

يفحص المثبّت وحدات Qt ويستخدم بيئة Python خاصة عند غياب الحزم أو عدم توافقها. أخطاء المكتبات الأصلية تحتاج إلى تثبيت حزم التوزيعة الموضّحة في دليل المتطلبات. يحافظ التحديث وإلغاء التثبيت على الإعدادات والسجلات والنسخ الاحتياطية.

لإلغاء التثبيت:

```bash
sudo /usr/local/share/adminw21/uninstall.sh
```

راجع [نطاق الميزات](FEATURE_STATUS.md) و[تقرير الفحص](TEST_REPORT.md). الفحص المحلي لا يثبت التوافق مع كل توزيعات Linux أو جلسات سطح المكتب.
